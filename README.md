# 👶 Motherhood – AI-Powered Support Platform

**Motherhood** is an intelligent, cross-platform application designed to support new mothers in caring for their infants. It combines AI-powered baby cry analysis, peer-to-peer communication, a second-hand marketplace, and expert parenting resources — all in one unified platform.

## 🚀 Features

- 🎤 **AI Cry Recognition**  
  Upload or record baby cries and receive intelligent analysis based on trained machine learning models (TensorFlow).

- 🛍️ **Marketplace for Moms**  
  Buy, sell, and exchange second-hand baby products like toys, clothes, and strollers in a secure community.

- 💬 **Community Chat**  
  Real-time messaging space where mothers can ask questions, share advice, and support one another.

- 📚 **Educational Hub**  
  Access daily parenting tips and expert-curated articles on infant health, nutrition, and development.

- 🔐 **User Authentication**  
  Secure login with email verification and token-based access.

## 🛠️ Tech Stack

| Layer       | Technologies |

| Backend     | ASP.NET Core, Flask |
